# Tic-Tac-Toe-Console-Game-in-C
A console-based Tic-Tac-Toe game in C Programming language for two players. Players alternate placing X or O on a 3×3 grid, aiming to align three symbols horizontally, vertically, or diagonally. The program detects wins, draws, and invalid moves. Great for beginners learning C loops, arrays, conditions, and game logic.
